Boutique Hafsa

 Description du projet

Boutique Hafsa est une application web développée avec HTML, CSS et JavaScript. Elle permet de consulter les commandes des clients, de rechercher des informations et de visualiser les détails des produits.

 Structure générale

Le projet est organisé en plusieurs dossiers. Le fichier index.html contient la structure de la page, le dossier css gère la présentation, le dossier js contient les fonctionnalités JavaScript et le dossier data regroupe les trois fichiers JSON liés. Le dossier images contient les photos des produits.

 Fonctionnalités principales

L’application permet de rechercher les commandes par nom de client, de filtrer les résultats par statut et par catégorie, et de consulter les détails de chaque commande. Elle affiche également des indicateurs calculés automatiquement et le montant total des achats.

 Instructions pour lancer le projet

Pour utiliser l’application, il faut télécharger le projet et ouvrir son dossier dans Visual Studio Code. Ensuite, il suffit de lancer index.html avec Live Server pour afficher la boutique dans le navigateur et charger les données JSON.
